# Tallyho logo kit

The mark: a magenta speech bubble ("…says") holding tally marks (counting the
votes / keeping score) with a gold spark. Palette: ink #0B1026, magenta #FF2E88,
violet #C026D3, cyan #22D3EE, gold #FFC53D, cream #FBF7EF.

- tallyho-badge.png / .svg      — icon only, transparent (avatars, favicons, overlays)
- tallyho-badge-ink.png         — icon, ink-bubble variant
- tallyho-wordmark(.svg/.png)   — horizontal lockup, transparent
- tallyho-wordmark-onink.png    — horizontal lockup on brand background
- tallyho-stacked.png           — stacked lockup + tagline, transparent
- tallyho-stacked-onink.png     — stacked lockup on brand background (great for invite covers)

SVGs are the source of truth (infinitely scalable). Regenerate: scratchpad/tallyho-logo/generate.mjs
